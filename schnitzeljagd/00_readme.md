Plankton hat das Lösungswort gestohlen und die Buchstaben überall in Bikini Bottom versteckt.
Jeder Aufgabenordner (01, 02, ...) ist eine Station. An jeder Station findest du einen Buchstaben.

In diesem Ordner findest du die Datei "00_solution".
Schreibe dort immer das Ergebnis der Aufgaben hinein.
Am Ende sollte ein Lösungswort entstehen.

Beginne, indem du in den Ordner 01 gehst. Dort findest du eine Datei mit
dem Namen "aufgabe". Darin steht, was du als Nächstes tun sollst.

In diesem Ordner findest du außerdem eine Datei mit generellen Tipps ("00_tipps").
